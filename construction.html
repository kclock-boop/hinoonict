IMPORT FROM EXCEL

엑셀 공사 자료 확인

첨부 양식을 자동으로 연결합니다.

공사번호 → 공사번호 / 요청일 → 시작일 / 종료예정일 → 마감일 / 실작업일 → 완료일

실작업일이 있으면 ‘완료’, 없으면 진행상태에 따라 분류합니다. ‘입력여부’는 완료 판정에 사용하지 않습니다. 날짜·마감 색상·알림은 반영 후 자동으로 계산됩니다.

기존 공사 갱신을 선택해도 엑셀에 없는 공사는 삭제하지 않습니다. 비어 있거나 없는 주소·담당자·발주처·메모는 기존 값을 유지합니다.

엑셀 공사 반영 미리보기
엑셀 행반영공사번호 · 주소구분시작일마감일완료일진행 상태확인 사항

오류가 있는 행은 원본 엑셀에서 수정한 뒤 다시 불러와 주세요. 수식이 있는 파일은 Excel에서 계산 후 저장한 최신 파일을 선택하세요.

이 파일은 현재 브라우저에서 읽으며 서버에 업로드하지 않습니다. ‘반영하기’를 눌러야 저장됩니다. 원본 엑셀 변경을 실시간 감지하는 기능은 아닙니다.
