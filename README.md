# 하이눈정보통신 기업소개 홈페이지

회사소개, 사업분야, 주요실적, 회사연혁, 사업 문의를 담은 1차 홈페이지 초안입니다.

## 확인 방법

`index.html`을 브라우저에서 열면 됩니다. `assets` 폴더를 함께 보관하세요.
PC와 모바일 화면에 대응하며 모바일 메뉴를 제공합니다.
전화·이메일 버튼은 기기의 전화·메일 프로그램을 연결합니다.

## 구성

- `index.html`: 홈페이지
- `assets/architecture.jpg`: 지명원에 수록된 건축 이미지. 실제 사옥 사진을 의미하지 않습니다.
- `홈페이지_미리보기.png`: PC 화면 미리보기
- `제작메모.txt`: 내용 출처와 후속 검토사항

## 참고 및 검토사항

- 디자인 참고: [삼목기업 홈페이지 저장소](https://github.com/kclock-boop/sammok)
- 회사정보 및 실적은 제공된 회사 지명원을 기준으로 작성했습니다.
- 공식 로고 대신 초안용 H 문자 표식을 사용했습니다.
- 공개 전 회사정보의 최신 여부, 실적 공개 가능 여부, 이미지 사용권을 확인해야 합니다.
- 원본 PDF와 개인별 훈련 정보는 저장소에 포함하지 않습니다.
